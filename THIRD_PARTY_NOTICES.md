# Third-party source notes

- **Riot Games / Data Dragon:** bundled static game data is Riot-derived content, not original project code. Riot developer documentation permits game-specific static data for development, but Riot IP is not relicensed by this repository. Preserve the non-affiliation notice and review the current [Developer API Policy](https://developer.riotgames.com/docs/lol#developer-api-policy), [General Policy](https://developer.riotgames.com/policies/general), and [Legal Jibber Jabber](https://www.riotgames.com/en/legal) before public release. Some terms address use of Riot IP in apps differently; this notice is not a legal determination. The bundled dataset includes versions `16.21.1` and `16.22.1`.
- **ARAM Mayhem data:** the bundled `data/aram-mayhem/` snapshot declares **CC BY 4.0** and includes source/license metadata. Required credit: [Data: arammayhem.com](https://arammayhem.com/data/). Keep its attribution and license metadata with redistributed copies.
- **OP.GG MCP:** the app queries the public endpoint at `https://mcp-api.op.gg/mcp` on demand. The upstream [MCP server source](https://github.com/opgginc/opgg-mcp) is MIT-licensed; that code license does not license OP.GG's service data. OP.GG's Help Center and Terms have different wording on crawling versus redistribution, so response snapshots, source-derived pilot profiles, and generated reports embedding those records are ignored by Git until the publication terms are confirmed.
- **Meraki Analytics `lolstaticdata`:** optional runtime knowledge adapter. The upstream repository identifies MIT for its software and asks users to credit Meraki and the League of Legends Wiki. Champion ability text/data provenance is separate from the parser license; this project does not bundle a Meraki response snapshot. See [upstream repository](https://github.com/meraki-analytics/lolstaticdata).
- **CommunityDragon:** adapter exists but is not enabled for ingestion; no extracted CommunityDragon dataset is bundled. The license/reuse status for extracted game data was not verified.
- **Electron and npm dependencies:** the lockfile resolves Electron `45.2.1` and public npm packages. The package-lock currently declares MIT (10 packages), ISC (2), and Apache-2.0 (1); inspect bundled package notices again before making a binary release.
- **Certificate:** `src/adapters/riotgames.pem` begins with `BEGIN CERTIFICATE`; it is a public certificate, not a private key. Its provenance should still be confirmed when maintaining the Riot local-client adapter.

All source-derived records should retain source, source patch, retrieval date, and verification state. An unknown or mismatched source patch must not override current Data Dragon data.

No repository-wide `LICENSE` is included yet. Do not interpret this file as granting a license over Riot content, third-party source data, or the ARAM Mayhem snapshot beyond its stated CC BY terms.
